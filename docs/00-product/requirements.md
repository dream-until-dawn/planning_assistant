# 需求规格（FR / NFR）

编号规则：`FR-<模块>-<序号>` 功能需求，`NFR-<类别>-<序号>` 非功能需求。
**期次**列：V1 = 首个 Android 包必须交付；V2+ = 后续，但架构需留口。
每条需求都必须可验收；「验收标准」列写的是测试用例要断言的东西。

---

## 1. 任务模型 FR-TASK

| 编号 | 需求 | 期次 | 验收标准 |
|---|---|---|---|
| FR-TASK-01 | 创建**单项任务**：标题、可选描述、可选计划时间段、分类、优先级 | V1 | 仅填标题即可保存；其余字段留空时使用配置中心默认值 |
| FR-TASK-02 | 创建**阶段事项**：一个任务包含 2..N 个有序阶段，每阶段有独立标题、时间段、完成状态 | V1 | 阶段可增删改、可拖拽重排；父任务进度 = 已完成阶段数 / 总阶段数 |
| FR-TASK-03 | 创建**定时计划**：按日/周/月/年及自定义间隔重复 | V1 | 支持「每 N 天」「每周一三五」「每月 15 号」「每月最后一个周五」「每年 5 月 20 日」 |
| FR-TASK-04 | 重复任务支持结束条件：永不结束 / 重复 N 次 / 到某日期止 | V1 | 三种条件均能正确截断展开序列 |
| FR-TASK-05 | 重复任务的**单次例外**：跳过某一次、或只改某一次的时间/标题 | V1 | 修改单次不影响其余次；跳过的次数不出现在任何视图 |
| FR-TASK-06 | 重复任务支持「本次及以后」批量修改 | V1 | 原规则在分割点截断，新规则从分割点起生效，历史记录保持不变 |
| FR-TASK-07 | 阶段事项与定时计划**可组合**（重复发生的多阶段事项） | V1 | 每个发生实例拥有独立的阶段完成状态 |
| FR-TASK-08 | 任务完成 / 取消完成 / 跳过 / 归档 / 删除（软删除） | V1 | 删除进回收站，30 天内可恢复；见 [任务生命周期](../02-domain/task-lifecycle.md) |
| FR-TASK-09 | 子任务清单（checklist）作为轻量拆分手段，区别于阶段 | V1 | checklist 项不参与甘特/时间轴排布，只在详情页显示 |

## 2. 视图 FR-VIEW

| 编号 | 需求 | 期次 | 验收标准 |
|---|---|---|---|
| FR-VIEW-01 | **时间轴视图**：单日纵向时间刻度，任务按时间块排布，支持重叠并排 | V1 | 同一时段 N 个任务均可见且不遮挡；无时间的任务归入顶部「随时」区 |
| FR-VIEW-02 | **列表视图**：按日期/分类/优先级分组，支持筛选与排序 | V1 | 分组维度可切换；筛选条件可叠加；空态有插画与引导 |
| FR-VIEW-03 | **日历视图**：月视图 + 周视图，格子内显示任务标记 | V1 | 点击日期联动下方列表；今日高亮；跨月滑动流畅 |
| FR-VIEW-04 | **竖向甘特视图**：纵轴为时间（向下推进），横轴为泳道，展示跨天任务与阶段条 | V1 | 阶段条按阶段颜色分段；可缩放时间粒度（日/周/月） |
| FR-VIEW-05 | 四视图共享同一筛选状态与选中态 | V1 | 在 A 视图设的筛选，切到 B 视图仍生效 |
| FR-VIEW-06 | 视图间切换保留滚动位置与当前聚焦日期 | V1 | 日历选中 9/20 → 切时间轴 → 显示 9/20 |
| FR-VIEW-07 | 快速新增入口在所有视图常驻，且能带上下文（当前日期/时段） | V1 | 在时间轴 14:00 处长按新增，新任务默认时间为 14:00 |

## 3. 配置 FR-CFG

| 编号 | 需求 | 期次 | 验收标准 |
|---|---|---|---|
| FR-CFG-01 | 所有可配置项**都有默认值**，用户不配置也能完整使用 | V1 | 全新安装、不进设置页，所有功能可用（由「零配置冒烟测试」覆盖） |
| FR-CFG-02 | 主题配置：明暗模式、主色、圆角强度、字号缩放、动效开关 | V1 | 改动即时生效，无需重启 |
| FR-CFG-03 | 分类管理：增删改、颜色、图标、排序、设为默认分类 | V1 | 删除分类时其下任务迁移到「未分类」而非级联删除 |
| FR-CFG-04 | 视图偏好：默认视图、一周起始日、时间轴刻度、是否显示已完成 | V1 | 冷启动进入用户设定的默认视图 |
| FR-CFG-05 | 提醒偏好：默认提前量、免打扰时段、是否合并通知 | V1 | 免打扰时段内的提醒顺延到时段结束 |
| FR-CFG-06 | 数据管理：全量导出 JSON、导入（合并/覆盖）、自动本地备份 | V1 | 导出文件可被导入还原，还原后数据等价（由往返测试覆盖） |
| FR-CFG-07 | 配置项**注册表化**：新增一个配置项只需加一条声明，UI 自动渲染 | V1 | 见 [配置中心规格](../03-design/settings-spec.md)；新增配置不改设置页代码 |
| FR-CFG-08 | 未开放给用户的配置项以默认值静默生效，且可通过导入的配置文件覆盖 | V1 | 隐藏配置项在导出 JSON 中可见 |

## 4. 提醒 FR-NOTI

| 编号 | 需求 | 期次 | 验收标准 |
|---|---|---|---|
| FR-NOTI-01 | 任务可设置一个或多个提醒（相对开始时间 / 绝对时刻） | V1 | 相对提醒随任务时间改动自动重算 |
| FR-NOTI-02 | 重复任务的提醒按**滚动窗口**排期，不一次性排无限个 | V1 | 见 [通知设计](../04-platform/notifications.md)；窗口耗尽前自动续排 |
| FR-NOTI-03 | 开机后自动恢复已排期的提醒 | V1 | 重启设备后待触发提醒不丢失 |
| FR-NOTI-04 | 精确闹钟权限被拒时降级为非精确提醒，并在 UI 明确告知 | V1 | 有可见的权限状态入口与一键申请 |
| FR-NOTI-05 | 通知栏常驻「今日概览」 | V2 | — |

## 5. 数据与同步 FR-DATA

| 编号 | 需求 | 期次 | 验收标准 |
|---|---|---|---|
| FR-DATA-01 | 全部数据本地持久化，App 强杀不丢已提交写入 | V1 | 持久化集成测试 + 崩溃恢复用例 |
| FR-DATA-02 | 每条记录携带**同步信封**字段 | V1 | 见 [数据模型 §5](../02-domain/data-model.md)；字段随导出 JSON 一并输出 |
| FR-DATA-03 | 所有写操作产生**变更日志（outbox）** | V1 | 变更日志可回放重建状态（由回放一致性测试覆盖） |
| FR-DATA-04 | 导出格式为**自描述 JSON**：含 schema 版本，服务端可独立解析 | V1 | 提供 JSON Schema 文件；导出样例通过 schema 校验 |
| FR-DATA-05 | DB schema 迁移可测试、可回滚验证 | V1 | 每次 schema 升版必须有迁移测试，见 [测试策略](../05-engineering/testing-strategy.md) |
| FR-DATA-06 | 云端同步（推拉 + 冲突解决） | V3 | — |
| FR-DATA-07 | 云端读取任务并发送邮件提醒 | V3 | — |

## 7. 非功能需求 NFR

### 7.1 性能 NFR-PERF

| 编号 | 需求 | 阈值 | 怎么测 |
|---|---|---|---|
| NFR-PERF-01 | 冷启动到首屏可交互 | ≤ 1.5s（中端机） | 集成测试打点 + 手工基准 |
| NFR-PERF-02 | 1000 任务下视图滚动 | 掉帧率 < 1% | `flutter run --profile` + timeline 采样 |
| NFR-PERF-03 | 单次任务写入到 UI 更新 | ≤ 100ms | 集成测试计时断言 |
| NFR-PERF-04 | 重复规则展开 1 年实例 | ≤ 50ms | 领域层基准测试，作为回归门禁 |

### 7.2 可靠性 NFR-REL

| 编号 | 需求 |
|---|---|
| NFR-REL-01 | 任何未捕获异常必须落本地日志且不静默吞掉；Release 包不因领域异常闪退 |
| NFR-REL-02 | DB 迁移失败必须可检测，并保留升级前数据副本 |
| NFR-REL-03 | 时间相关逻辑在跨时区、跨夏令时、闰年边界下行为明确（有专门测试集） |

### 7.3 可维护性 NFR-MAINT

| 编号 | 需求 |
|---|---|
| NFR-MAINT-01 | 分层依赖方向由自动化检查强制（Presentation → Application → Domain ← Data） |
| NFR-MAINT-02 | 领域层零 Flutter 依赖，可在纯 Dart VM 下测试 |
| NFR-MAINT-03 | 新增一个「任务视图」不需要改动领域层与数据层 |
| NFR-MAINT-04 | 新增一个配置项 ≤ 1 处改动 |

### 7.4 可访问性与本地化 NFR-A11Y

| 编号 | 需求 |
|---|---|
| NFR-A11Y-01 | 正文文字对比度 ≥ 4.5:1（可爱清新的低饱和配色**必须**通过这条，不得为了好看牺牲可读） |
| NFR-A11Y-02 | 支持系统字号缩放至 200% 不破版。**注意应用内 `theme.fontScale`（≤1.4）与之相乘**，实际须验到 2.8 —— 见[设计系统 §3.4](../03-design/design-system.md#34-缩放是两层相乘golden-必须覆盖到实际最坏值) |
| NFR-A11Y-03 | 所有动效可全局关闭，并响应系统「减少动态效果」 |
| NFR-A11Y-04 | 文案全部走本地化资源，首发中文，架构支持追加语言 |

### 7.5 隐私 NFR-PRIV

| 编号 | 需求 |
|---|---|
| NFR-PRIV-01 | V1 不联网、不采集任何遥测；权限只申请通知与精确闹钟 |
| NFR-PRIV-02 | V3 云同步必须是用户显式开启的可选项，且传输前加密 |
