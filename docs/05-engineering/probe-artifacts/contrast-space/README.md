# 探针：24 位色彩空间能否穷举

**结论：能。对比度校验 377 ms；连同一个有代表性的 `derive()` 是 4.4 s。**

## ⚠️ 作用域：这个探针回答了什么、**没有**回答什么

| | |
|---|---|
| ✅ 回答了 | 全空间**能否**枚举（能，成本可接受） |
| ❌ 没回答 | 该枚举**判什么谓词** |

第一版探针用的判据是「主色 vs 表面 ≥ 4.5:1」。**那是错的**，而且错得可检验：
默认主色 `#7FD1C1` 对三个表面分别是 **1.72 / 1.78 / 1.58** ——
这条判据会拒掉出厂默认值。

> **拒掉自家默认值的判据，不可能是正确的验收规则。**
> 这是最便宜的自检，一行就能跑。

这次的失败形状与本项目前几轮不同，值得单记：**前几轮是覆盖不足
（采样冒充全称）；这次覆盖是满的，错在谓词。** 而覆盖满会让结论更可信 ——
「16,777,216 个一个不落」听起来无可辩驳，实际只是把一个错误判据
执行得非常彻底。谓词没定死之前，穷举跑的是一个精确的错误答案。

## 为什么要探这个

[设计系统 §10](../../../03-design/design-system.md) 要求「用户能选的颜色范围内
不允许出现不达标组合」。`theme.primaryColor` 是用户可配的（[配置注册表](../../../03-design/settings-spec.md)），
所以这条断言的对象是**一个空间**，不是几个样本。

拿几个样本色测通过，证明不了「范围内不允许出现」—— 这与本项目反复撞的
「单样本推全称结论」是同一件事，只是这次的域是颜色。

于是先问一个可测的问题：**全空间到底能不能穷举？** 能的话就不必谈采样。

## 实测

```
（一）只算对比度
穷举 16777216 色 × 6 表面 = 100663296 次对比度计算       377 ms

（二）连同一个有代表性的 derive()（RGB→HSL→调 L→HSL→RGB，3 个派生角色）
16777216 主色 × 3 派生角色 × 6 表面 = 301989888 次校验    4424 ms
```

（二）才是真正的验收形态 —— 要枚举的是**主色**，每个都得跑真实的
`derive()`，再校验它派生出的全部前景×背景对。第一版探针只测了（一），
也就是便宜的那半；可能不可行的恰恰是另一半。

**由此得到一条 `derive()` 的实现约束**：16,777,216 次调用要留在秒级，
它必须基本无堆分配。用 `Color` / `HSLColor.fromColor` 这类对象化 API
逐色构造，开销会高一到两个数量级，那时全集穷举就不再可行 ——
**这个约束必须在写 `derive()` 之前就知道，否则写完要返工。**

6 个表面 = canvas / card / sunken × 明暗两主题。

关键在于 sRGB 通道线性化可以查表（每通道只有 256 个取值），
于是每个颜色的相对亮度是「3 次查表 + 2 乘 2 加」。
`math.pow` 只在建表时调 256 次，不在内循环里。

## 因此 §10 的断言口径定为「全集」

不是「若干代表色」，是 **16,777,216 个可选颜色一个不落**。
这与 M1 里扫完整个 tz 数据库（8846 次春季跳变）找「23:59 不存在」的组合
是同一个做法：**域能枚举就枚举，不要采样后声称全称**。

## 这个探针**不是**最终测试

它只回答「穷举可行吗」。真正要断言的是**校验器本身**：

> 对每一个可选颜色，要么被接受（且派生出的整套配色达标），
> 要么被拒绝（且给出的最近达标色确实达标）。

还需要一条「拒绝集非空且边界正确」的证明 —— 否则一个「全部接受」的
校验器也能让「被接受的都达标」这句话为真（因为它同时让派生规则背锅），
而一个「全部拒绝」的校验器则让整个配置项失去意义。

实现时见 `test/design/`。

## 追加：固定派生系数不通用（全空间枚举得出）

评审提出把 `brand.primary` 拆成 `.fill` / `.graphic`，给的图形色是
「主色亮度 × 0.62」。对默认主色成立，**对全集不成立**：

| 固定系数 | 派生后仍不达标的主色 | 占比 |
|---|---|---|
| 0.62 | 2,064,103 | **12.3%** |
| 0.45 | 290,380 | 1.7% |

改成二分求解「仍达标的最大亮度」后，**16,777,216 个主色全部有解**，
平均压到原亮度 87.3%，最狠一档 28.4%，全空间求解 18.2 s。

这一条正是全集穷举存在的意义：**它把「对我试的那个色管用」与
「对全集管用」分开了。** 只拿默认主色验证的话，12.3% 的失败面看不见。
